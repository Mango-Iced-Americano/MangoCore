## 2026-08-02

### root= 命令行选择器 + mango.tools 移除

**涉及文件：**
- `libs/mango-kernel-core/src/bootargs.rs` — `BootConfig` 新增 `root_from_cmdline` 标志；`root=` 优先于 `mango.root=`，两者命中时均置显式标记。
- `libs/mango-kernel-core/src/bootargs_tests.rs` — bootargs 解析测试（root 优先级、显式 `root=initramfs`、默认未显式选择）。
- `os/src/main.rs` — 删除平台默认 root 覆写，不再以 `default_root()` 覆盖解析后的命令行配置。
- `os/src/fs/boot_block.rs` — `mount_boot_block_devices` 显式 root 语义：显式 `root=initramfs` 保留 initramfs（跳过 `/sdcard`）；其他非空显式 root 经 `resolve_block_device`（剥除单个 `/dev/` 前缀、拒绝空/`.`/`..`）解析并挂载，解析不到或挂载失败只打印错误、不回退；未显式提供 root 时回退首原始块设备（`get_block_device(0)`）。
- `docs/03_fs/init-and-rootfs.md` — 同步 root 选择器语义与驱动命名模型。
- 用户决定移除 `mango.tools=`/`tools` 字段：内核只发布 `/dev` 节点，挂载 `/tools` 由 initramfs 用户态按需执行（对齐 Linux 语义）；`os/src/` 与 `libs/` 无 `mango.tools`/`mount_tools_disk` 残留。

**验证：**
- Docker `mangocore-os-dev-1`（`/root/projects/MangoCore -> /app`）：`cargo test -p mango-kernel-core` ✅。
- `make kernel ARCH=rv64 PROFILE=normal` ✅、`make kernel ARCH=la64 PROFILE=normal` ✅（严格串行）。
- `make -C os ktest-run ARCH=rv64 PROFILE=normal KTEST=block_device` ✅（8 passed、0 failed）。
- `make -C os ktest-run ARCH=rv64 PROFILE=normal KTEST=dw_mshc` ✅（5 passed、0 failed）。
- `make test ARCH=rv64 PROFILE=regression` ✅（22 passed、0 failed、1 skip）。

**备注：** 此为块设备规范化四步重构的 Step 3。显式 root 选择器解析不到设备或设备无可挂载文件系统时，不执行首盘回退，保持 initramfs 可用（对调试与 CI 友好）。

### 块设备驱动声明命名风格并移除探测顺序角色

**涉及文件：**
- `os/src/drivers/block/{block_dev,descriptor,mod}.rs` — 新增驱动声明的字母/十进制命名风格，按风格独立计数；删除 `BlockDeviceRole`、角色查询及空盘 panic，空盘回退为 `DummyBlockDevice`。
