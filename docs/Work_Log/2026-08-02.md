## 12:12 — B66 futex nofault 原子注册

**Date:** 2026-08-02 12:12 +08:00
**Author:** AI:GPT/Codex + DeepSeek | Human:Pneuma
**Tags:** [area:smp, area:task, area:mm, area:syscall, type:fix, risk:concurrency]
**Mango Gate:** skill loaded=yes; references=debugging-patterns.md

**Summary:** futex WAIT/WAIT_BITSET/waitv 不再在 `FutexTable` 自旋锁内调用可能缺页的
`UserPtr::read()`。syscall 层先在锁外读取 word、比较 expected 并解析当前 key；注册侧在
锁外分配 waiter、clone VM，随后只在 table 锁内用非阻塞 `AddressSpace::try_read()` 校验
shared backing、PTE/读权限并读取 u32。值比较成功后在同一 table 临界区发布 waiter，关闭
lost-wake 窗口；VM 锁忙或映射变化只在发布前返回内部 Retry，释放 table 后完整重试。

**Files:**

- `os/src/mm/address_space.rs` — 增加只用于外层不可睡眠临界区的非阻塞 `try_read()`。
- `os/src/task/threads.rs` — 增加 nofault word 检查与内部 `FutexWaitOutcome::Retry`；
  删除 table 锁内 faultable closure 和入队后的第三次读取，wait/waitv 统一原子注册。
- `os/src/syscall/process/futex.rs` — 在 syscall 锁外循环 fault-in、比较并重算 key；
  相对 timeout 固定一次绝对 deadline，waitv 描述符快照一次、每次 Retry 重建全部条目。
- `docs/05_process/`、`docs/{01_architecture,04_mm,10_plan}/`、`AGENTS.md` — 同步
  条件式 table→VM try-lock 边、线性化证明和剩余边界。
- `.agents/skills/mango-workflow/references/debugging-patterns.md` — 沉淀“锁外 fault-in、
  锁内 nofault 比较并发布”的可复用模式。
- `docs/00_overview/AI-Usage-Report.md`、
  `docs/Work_Log/evidence/2026-08-02/smp-b66-futex-nofault-summary.md` — 归档协作与证据。

**Summary:** process-shared futex 不再用可复用的 raw PPN + offset 充当长期队列键。

非空 shared queue 持有一份 backing pin，空队列删除才释放，从生命周期上排除旧队列错误
命中新分配到同一 PPN 的无关页面。
