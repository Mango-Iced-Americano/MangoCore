### dw-mshc 声明可靠 flush：修复 VF2 实板 ext4 挂载 EROFS

**根因：** `os/src/fs/ext4_another/fs.rs` `Ext4FileSystem::open` 检查 `block_device.supports_reliable_flush()`；dw-mshc 驱动未实现 `supports_reliable_flush()`/`flush()`，BlockDevice trait 默认值（`false`/`FlushUnsupported`）导致 ext4 挂载返回 EROFS（"Read-only file system"）。QEMU virtio-blk 实现两者为 true，故 QEMU 下 ext4 挂载正常。

**修复：** dw-mshc 写路径本身可靠——`write_sector`（mmio.rs）发 CMD24+DAT_WR 后 `wait_card_ready`（CMD13 轮询）确认卡就绪才返回，写入已落介质；板上写自检（末块写+读回）PASS。因此：
- `fn supports_reliable_flush(&self) -> bool { true }` — 返回的写即持久。
- `fn flush(&self) -> BlockDeviceResult { Ok(()) }` — 无宿主写缓存需排空，no-op 成功。

`PartitionBlockDevice` 委托父设备 flush，故 `mmcblk0p1` 自动生效。

**涉及文件：**
- `os/src/drivers/block/dw_mshc.rs` — BlockDevice impl 新增 `flush()`/`supports_reliable_flush()`；未改动 mmio.rs/sd.rs 数据路径、jh7110.rs、partition.rs、ext4_another。
