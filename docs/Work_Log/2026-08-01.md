## 00:28 — B50 Per-CPU zombie 回收

**Date:** 2026-08-01 00:28 +08:00
**Author:** AI:GPT/Codex + DeepSeek | Human:Pneuma
**Tags:** [area:smp, area:task, type:feature, risk:concurrency]
**Mango Gate:** skill loaded=yes; references=debugging-patterns.md

**Summary:** 删除 `TASK_MANAGER` 中的全局 zombie 队列，让每个 CPU 在自己的
idle 栈上回收退出 TCB，同时保留 wait/auto-reap 的跨 CPU 按 pid 清理能力。

**Files:**

- `os/src/task/processor.rs` — 在 `CpuTaskState` 中增加本地 zombie 队列/计数，CPU0
  和 AP 调度循环都在本地 idle 栈 drain；跨 CPU 收集任意时刻只持有一把队列锁。
- `os/src/task/manager.rs` — 删除全局 `zombie_queue`，`finish_switch_out()` 把
  `Zombie` Arc 交给 owner CPU；按 pid 清理先摘取 interruptible zombie，再扫描
  Per-CPU 队列，不嵌套锁且在锁外析构。
- `os/src/task/mod.rs` — 将 zombie 诊断/收集 API 的重导出改到 processor 层。
- `os/src/kernel_tests/smp.rs` — 新增 `zombie_reclaims_on_owner_idle`，并让 kernel-stack
  回收用例等待 owner CPU 真正释放 TCB，不再人工抽干全局队列。
- `docs/10_plan/smp-8core-implementation.md` — 标记 Phase 3 Per-CPU zombie 所有权闭环完成。
- `docs/05_process/{scheduler,task-process-scheduler,architecture,exit-wait}.md` — 同步当前
  调度器、切栈后 Arc 交接和 PCB/TCB zombie 分层。
- `docs/09_debug/la64_on_board/260710/19-zombie-kernel-stack-slot-reclamation.md` — 增加
