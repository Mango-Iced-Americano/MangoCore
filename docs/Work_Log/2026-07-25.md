## 2026-07-25

### 恢复合并丢失的 ext4 后端配置并适配块设备 API

**涉及文件：**
- `os/Cargo.toml` — 恢复 optional ext4 后端依赖、特性定义与 another_ext4 默认后端。
- `os/src/fs/` — 适配 `BlockDevice`、`FileSystem::on_umount`、FAT PageCache 与动态挂载 API。
- `os/src/kernel_tests/ext4*` — 仅在 lwext4 后端启用对应测试，并适配可失败的块设备接口。
- `os/make/arch/rv64-settings.mk` — 将 objcopy 定位到项目固定 nightly 工具链。

**验证：**
- `make kernel ARCH=rv64 PROFILE=normal` ✅
- `make kernel ARCH=la64 PROFILE=normal` ❌：容器缺少 `/usr/bin/clang`，用户态链接器退出 127（与本次文件系统修改无关）。

**备注：** LA64 失败前未报告 Rust 编译错误；需在开发容器安装 clang 后重跑。
