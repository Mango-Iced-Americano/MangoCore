## 2026-07-25

### Redesign CI pipeline to 5-layer sequential build

Replaced the single `full-test` job with a 5-layer pipeline on the `rvqemu` platform:

| Layer | Job | What | Timeout |
|-------|-----|------|---------|
| 0 | `toolchain-contracts` | Toolchain provisioning contracts (unchanged) | 5 min |
| 1 | `clippy` | `cargo clippy --features "board_rvqemu block_virt" -- -D warnings` | 15 min |
| 2 | `cargo-test` | `cargo test --features "board_rvqemu block_virt"` | 15 min |
| 3 | `ktest` | `make -C os rv64-ktest` (kernel self-tests, no disks) | 15 min |
| 4 | `regression` | `make test ARCH=rv64 PROFILE=regression` (initramfs only) | 15 min |
| 5 | `comp` | `make -f make/rv64.mk comp` with mask=0xFDF, QEMU_TIMEOUT=7200 | 350 min |

**涉及文件：**
- `.github/workflows/ci.yml` — 完全重写，移除了双架构 serial full-test，改为 rv64-only 5 层顺序流水线

**关键变更：**
- 所有 job 使用 `docker compose up -d` / `docker compose exec` / `docker compose down` 模式
- 每层使用 `needs:` 确保顺序执行
- 显式传入 `RUSTUP_HOME=/root/.rustup` 和 `CARGO_HOME=/root/.cargo`
- comp job 包含磁盘清理、缓存、镜像下载解压、config 注入全流程
- 移除 LA64 相关步骤（rv64 only for speed）
- 保留 `toolchain-contracts` job 不变

**验证：**
- `python3 -c "import yaml; yaml.safe_load(open('.github/workflows/ci.yml'))"` ✅ — YAML 语法合法
- 未做双架构编译验证（仅 CI 配置变更，不涉及内核源码）

**备注：** 需要确保 `make -C os rv64-ktest` 和 `make -C os conf-inject` 等命令在 Docker 容器内路径正确。`make rv64-ktest` 在根目录 Makefile 中不存在，已更改为 `make -C os rv64-ktest`。
