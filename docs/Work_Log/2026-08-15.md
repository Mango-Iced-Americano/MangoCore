## inet_test auto profile：连通性探测决定整套开关，离线整体 SKIP

**Date:** 2026-08-15
**Tags:** [area:net, area:testing, type:feature]

**Summary:** regression 的 inet_test 从固定 `core` 子集改为 `auto`：先做有界 DNS 连通性探测（UDP A 查询 + `ppoll` 5s），通则跑本地+外部全套，不通则以专用退出码 42 整体 SKIP；external 阶段单测失败降级为 skip（CDN/服务器行为抖动，非内核回归）。

**Files:** `user/src/bin/inet_test.rs`、`user/src/bin/regression/main.rs`

**改动：**
- `inet_test`：`connectivity_probe()`（DNS 查询 + ppoll 5s 限时，不用阻塞 connect/recv 防无界等待）；`auto` profile = Core|Loopback|External（不含 Veth——需 iproute2，regression 精简 initramfs 无）；probe 失败 → `exit(42)`；external 阶段失败 → 黄字 `# SKIP external (unreliable)`，不计 failed。
- `regression`：`run_child_timeout` 三态（Pass/Fail/Skip/Timeout），识别退出码 42 → `ok N # SKIP (no external connectivity)` 计 skipped；report() 按 outcome 分发。

**验证：**
- 有网（QEMU SLIRP）：inet auto 38/38 全过，含真实 `tcp_connect`、`tcp_send_recv`、`http_get`（www.baidu.com）、`dns+baidu/bilibili`、`udp_external_dns`、route 03/04/05——**真实互联网连通**。
- 无网（QEMU 去掉 net 设备）：`ok 26 inet_test # SKIP (no external connectivity)`，regression 27 passed + 1 skipped → **L4 PASS 不误报**。
- regression 28/28、lint 四格、la64 build 全过。
- 观测：baidu CDN 解析 IP 动态变化（124.x → 103.x → 111.x），个别节点 keep-alive 不关连接会让阻塞 recv 超时（60s watchdog）——这是 external 降级 skip 的直接原因。
