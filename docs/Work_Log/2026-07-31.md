### VF2 board FDT address alignment — accept standard word-aligned handoff

**涉及文件：**
- `os/src/hal/firmware/mod.rs` — 将 RV64 FDT 输入边界从错误的页对齐收紧改为 `u32` 所需的 4-byte 对齐。
- `os/src/hal/firmware/fdt.rs` — 在 header volatile `u32` 读取和 FDT snapshot 捕获路径使用同一 4-byte 对齐约束。
- `scripts/test-rv64-standard-fdt-boot-contract.sh` — 锁定“拒绝非 word-aligned、接受非页对齐 FDT”的启动 ABI 合同。

**根因：** VF2 U-Boot 按标准把板载 DTB 传入 `a1=0xf76df9b0`；该地址满足 `u32` 对齐，但不满足项目错误要求的 4 KiB 对齐，内核在 pre-heap FDT 解析前 panic：`RV64 boot requires an aligned FDT in a1`。

**验证：**

- GREEN：`scripts/test-rv64-standard-fdt-boot-contract.sh` ✅
- `make kernel ARCH=rv64 PROFILE=normal` ✅；`scripts/test-rv64-image-artifact.sh` ✅（9,735,376 bytes）
- `make kernel ARCH=la64 PROFILE=normal` ✅
- `make test ARCH=rv64 PROFILE=regression` ✅（22 passed, 0 failed, 1 skipped）
- VF2 第一次真实 `booti 0x40200000 - $fdtcontroladdr` 已验证 TFTP bytes、magic2 和首个 panic；修复 Image 已部署，等待重启后复验。

**备注：** pre-fix `booti` 后 Ctrl-C 未返回 U-Boot，必须物理重启；不会保存 U-Boot env。

### RV64 统一高-VMA FDT 启动 — AlreadyMapped panic 修复

**涉及文件：**
- `os/src/hal/arch/riscv/config.rs` — 新增 `KERNEL_PROGRAM_BASE = 0xffff_ffc0_4000_0000`，临时内核 ELF 映射窗口从低 0x2000_0000（与 early MMIO 恒等映射 PTE 碰撞）移至高半区
- `os/src/mm/kernel_space.rs` — `try_insert_program_area` 使用 `kernel_program_base()` 做边界检查；`KernelSpace::new()` 内核段改用 `kernel_map!`（经 `kernel_linked_to_phys` 转换）替代旧 `kernel_identical_map!`
- `os/src/mm/mod.rs` — 导出 `kernel_program_base`
- `os/src/task/task.rs` — `load_elf` 和 `TaskControlBlock::new` 使用 `kernel_program_base()` 做临时映射/解除

**根因：** `MMAP_BASE=0x2000_0000` 在高-VMA 布局下与 early MMIO（FDT `reg` 范围）的恒等映射 PTE 碰撞，`insert_program_area` 返回 `MemoryError::AlreadyMapped`。

**验证：** RV64 normal 编译 ✅、regression ✅（原始 panic 消失）

### RV64 trampoline PPN 转换修复 — sret 超时

**涉及文件：**
- `os/src/mm/kernel_space.rs` — 内核页表 trampoline PPN 改用 `kernel_linked_to_phys(strampoline)`
- `os/src/mm/address_space.rs` — 用户页表 trampoline（含 signal trampoline）统一用 `kernel_linked_to_phys`

**根因：** 高-VMA 链接后，`strampoline` 作为高半区虚拟符号被直接当物理 PPN 使用，导致 trampoline 映射到无效物理地址 → `sret` 无限异常循环（异常向量同样失效，Rust 页故障处理器无日志）。

**验证：** `make test ARCH=rv64 PROFILE=regression` → `=== REGRESSION PASS ===` ✅
