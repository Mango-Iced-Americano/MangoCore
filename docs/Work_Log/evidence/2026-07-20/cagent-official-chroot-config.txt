Environment:
  Docker image: zhouzhouyi/os-contest:20260104
  Container: lzm-cagent-run
  Mount: /home/lzm/projects/MangoCore -> /app

Kernel build:
  RV64: make rv64-kernel-build-only EXTRA_FEATURES=board_shell
  LA64: make la64-kernel-build-only EXTRA_FEATURES=board_shell
  Builds were executed sequentially in the 2026 Docker container.

Official images:
  Source archives: sdcard-rv-pub.img.gz, sdcard-la-pub.img.gz
  Each archive was expanded to a temporary 15032385536-byte sparse raw ext4 image.
  No os_test.conf or binary was injected into either official image.

Guest topology:
  MangoCore boots from its embedded ramfs/initramfs.
  The official x0 raw ext4 image is mounted by the kernel at /sdcard.
  /proc and /dev are bind-mounted into /sdcard/proc and /sdcard/dev.
  CAgent runs inside: chroot /sdcard /bin/bash
  Test working directory inside chroot: /glibc
  Test command: ./cagent_testcode.sh

QEMU:
  RV64: qemu-system-riscv64 -machine virt -kernel /app/kernel-rv -m 1024
        -nographic -smp 1 -bios default
        -drive file=/app/testresult/cagent-official/sdcard-rv-pub.img,if=none,format=raw,id=x0
        -device virtio-blk-device,drive=x0,bus=virtio-mmio-bus.0
        -device virtio-rng-device,bus=virtio-mmio-bus.2
        -device virtio-net-device,netdev=net,bus=virtio-mmio-bus.7
        -netdev user,id=net -no-reboot -rtc base=utc
  LA64: qemu-system-loongarch64 -machine virt -kernel /app/kernel-la -m 1024
        -nographic -smp 1
        -drive file=/app/testresult/cagent-official/sdcard-la-pub.img,if=none,format=raw,id=x0
        -device virtio-blk-pci,drive=x0 -device virtio-rng-pci
        -device virtio-net-pci,netdev=net0 -netdev user,id=net0
        -no-reboot -rtc base=utc

Completion policy:
  The unmodified official script ends with a bare `wait`, which also waits for
  the long-lived simple_llm_server. The host runner records all ten unique
  testcase result lines, waits two seconds for log flushing, then terminates
  QEMU. No guest test result is synthesized or rewritten.
