## 2026-08-07

### 修复 chroot 路径泄漏阻塞 BuildStorm bindgen

**涉及文件：**
- `os/src/fs/mod.rs` — 新增统一的进程 root-relative inode 路径转换。
- `os/src/fs/procfs/pid/fd.rs` — `/proc/<pid>/fd/*` 目标路径按进程 root 裁剪全局挂载前缀。
- `os/src/syscall/fs/sys_getcwd.rs` — 复用统一路径转换，避免 `getcwd` 泄漏 chroot 外路径。
- `os/src/syscall/fs/sys_chdir.rs` — chroot 后缓存 root-relative cwd，避免后续相对路径重新污染缓存。
- `os/src/syscall/fs/sys_fchdir.rs` — fchdir 同样按进程 root 更新 cwd 缓存。
- `.agents/skills/mango-workflow/references/debugging-patterns.md` — 沉淀 chroot 与 proc fd 路径泄漏排查模式。

**验证：**
- Docker 内 `make kernel ARCH=rv64 PROFILE=normal BUILD_ROOT=/tmp/mango-smp-chrootpath-rv` ✅
- Docker 内 `make kernel ARCH=la64 PROFILE=normal BUILD_ROOT=/tmp/mango-smp-chrootpath-la` ✅
- RV64 8 核/8G QEMU 已启动并完成 initramfs、ext4、bind mount；官方临时副本首次启动发现 journal/空闲计数未收敛，修复临时副本后可进入 PID1。真正 BuildStorm 阶段受 QEMU 非确定性 boot-hart/启动等待影响，尚未形成 `BUILDSTORM_COMPILE` 结果。
