Trigger and root cause:
  package_input_digest changed after wrapper/benchmark edits.
  The previous packaging step unconditionally re-ran GNU strip and patchelf.
  patchelf --set-interpreter on an already-bound Python ELF was not byte-idempotent.
  Repeating it grew usr/bin/python3.14 from 69856 to 73792 bytes and changed the artifact hash.

Fix and gate:
  strip runs only for ELF files still containing .symtab or .debug_* sections.
  patchelf runs only when PT_INTERP differs from the expected P4 current loader.
  The final PT_INTERP is always re-read and verified.
  After removing the package stamp, two consecutive full packaging runs both produced:
