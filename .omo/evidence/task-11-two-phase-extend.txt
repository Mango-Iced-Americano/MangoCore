Task 11 two-phase cached write evidence

Implemented:
- Added `Ext4FileSystem::prepare_cached_write()` in `os/src/fs/ext4/ext4fs.rs`:
  - Phase 1: For each logical block in the target range, checks if a physical block exists.
    If not (hole), calls `insert_inode_pblk_from()` to allocate a new block + extent.
  - Phase 2: If the new end offset exceeds current file size, calls `inode.inode.set_size()`
    followed by `write_back_inode()` to commit i_size before PageCache write.
  - After prepare_cached_write succeeds, the caller (Ext4OSInode::write_at, T10) writes
    data through PageCache::write(), which marks pages as dirty.
- This follows the DragonOS pattern: allocate blocks → commit i_size → write cached data.
- The old direct write path (ext4fs.write_at in file.rs) is preserved for symlink writes
  and other non-regular-file paths.
