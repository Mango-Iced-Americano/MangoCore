Task 4 metadata flush evidence

Changes made:
- Added `BlockCacheManager::flush_dirty_blocks(&self, block_device: &Arc<dyn BlockDevice>) -> Result<usize, SyscallErr>` in `os/src/fs/cache.rs`.
- The function collects dirty block data while holding each buffer lock, releases the lock before calling `block_device.write_block`, then reacquires buffers to clear dirty flags.
- This establishes an explicit BlockCache metadata flush API for later ext4 `sync_fs()` integration.

Abstraction boundary:
- Metadata blocks live in the old `BlockCacheManager`/`BufferCache` layer.
- File data pages live in the VFS `PageCache` layer.
- Final device I/O is performed through the caller-provided `Arc<dyn BlockDevice>`.
